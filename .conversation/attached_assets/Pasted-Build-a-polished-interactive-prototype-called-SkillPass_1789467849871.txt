Build a polished, interactive prototype called **“SkillPass – Digital Skill Passport & Competency Verification Platform.”**

This is a **college project prototype**, NOT a production application. Focus on excellent UI/UX, realistic demo data, and working interactions. Do not spend time building complex authentication, payment systems, or production-grade infrastructure.

## Main Idea

SkillPass is a digital platform where students create a verified digital record of their skills, projects, certificates, assessments, and competencies.

Recruiters can view and verify a candidate's Skill Passport instead of relying only on a traditional resume.

The main demo flow should be:

**Student → Add Skill → Take Assessment → Get Verified → Digital Skill Passport → QR Verification → Recruiter Views Candidate → Skill Match**

# 13. Important Prototype Requirement

Do NOT create unnecessary backend complexity.

Use:

**React + TypeScript + Tailwind + localStorage/mock data**

All buttons should actually work.

For example:

Create Skill → opens modal

Start Assessment → opens assessment

Submit Assessment → calculates score

Verify Skill → updates verification status

Generate QR → displays QR

View Passport → opens passport

Verify Passport → displays verified candidate

Add Evidence → adds evidence card

Recruiter Search → filters candidates

Skill Matching → calculates/displays match percentage

Use localStorage so data persists after page refresh.

# 14. Demo Scenario

Make sure the prototype can demonstrate this exact story:

1. Open SkillPass landing page.
2. Click “Create Skill Passport.”
3. Open student dashboard.
4. Show competency score and verified skills.
5. Go to Verify Skill.
6. Select Java.
7. Take the demo assessment.
8. Submit it.
9. Show “Java – VERIFIED.”
10. Open My Skill Passport.
11. Show the updated passport.
12. Click Generate QR.
13. Open Verify Passport.
14. Enter `SP-2026-00421`.
15. Show verified candidate information.
16. Open Recruiter Dashboard.
17. Search for Java + React.
18. Show candidate with 91% skill match.
19. Open the candidate's passport.

The entire prototype should feel like one connected product.

Before finishing, make sure there are no broken routes, console errors, empty buttons, or non-functional interactions.
